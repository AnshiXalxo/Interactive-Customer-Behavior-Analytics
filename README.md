# Interactive-Customer-Behavior-Analytics

📌 Overview

This project analyzes a retail company's consumer shopping behavior to help stakeholders understand purchasing trends, customer engagement, and the key factors that drive sales and repeat purchases. The end-to-end workflow covers data preparation, structured analysis, and an interactive Power BI dashboard for business decision-making.

🎯 Business Problem

A leading retail company wants to better understand its customers' shopping behavior in order to improve sales, customer satisfaction, and long-term loyalty. Management has noticed shifts in purchasing patterns across demographics, product categories, and sales channels (online vs. offline), and wants to know which factors — discounts, reviews, seasonality, or payment preferences — drive consumer decisions and repeat purchases.

Guiding question:

How can the company leverage consumer shopping data to identify trends, improve customer engagement, and optimize marketing and product strategies?

🗂️ Project Deliverables
Data Preparation & Modeling (Python) — Clean and transform the raw dataset for analysis.
Data Analysis (SQL) — Structure the data, simulate business transactions, and query it for insights on customer segments, loyalty, and purchase drivers.
Visualization & Insights (Power BI) — An interactive dashboard highlighting key patterns and trends.
Report & Presentation — A written summary of findings/recommendations plus a stakeholder-facing presentation.
GitHub Repository — All Python scripts, SQL queries, and dashboard files in one organized place.

🛠️ Tools & Technologies
Python (pandas, numpy) — data cleaning & preparation
SQL — data modeling & querying
Power BI — dashboard & visualization
GitHub — version control & project hosting


🚀 How to Use
Clone this repository.
Run the Python scripts in /python to clean and prepare the dataset.
Load the cleaned data using the SQL scripts in /sql to reproduce the analysis tables.
Open Customer_Behavior_Dashboard.pbix in Power BI Desktop to explore the interactive dashboard.
